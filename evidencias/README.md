# Carpeta de Evidencias — Informe Parcial 2

Estructura para organizar las capturas y registros de cada parte del examen.
**Toda captura debe mostrar fecha y hora del sistema.**
**Por cada prueba se guardan 3 capturas: Inicio · Proceso · Resultado.**

## Convención de nombres
```
YYYYMMDD_HHMM_<parte>_<prueba>_<momento>.<ext>
Ej: 20261110_1430_parte3_hydra_inicio.png
```

## Subcarpetas
| Carpeta | Contenido |
|---|---|
| `parte1_flask/` | Flujo Fábrica → Pedido → Pago, correo Yappy, JSON comprobantes, verificación Supabase. |
| `parte2_red/` | Packet Tracer: topología convergida, prueba HSRP (ping con R1 apagado), prototipo embebido en SO1/SO2. |
| `parte3_seguridad/` | nmap pre/post knocking, Hydra bloqueado por fail2ban, `ab` con y sin `limit_req`, curl HTTP vs HTTPS, tcpdump. |
